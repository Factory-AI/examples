# Factory Examples

Official example applications demonstrating Factory's capabilities.

## Examples

### [droid-chat](./droid-chat)

A chat interface built with Droid Exec in headless mode. Demonstrates:
- Server-Sent Events for real-time streaming
- Building interactive apps with Factory's headless CLI
- Chat with codebase functionality

[View tutorial →](https://docs.factory.ai/guides/building/droid-exec-tutorial)

## Getting Started

Each example includes its own README with setup instructions. Navigate to the example directory and follow the instructions there.
